# Validação do acesso simplificado

O login pede somente César ou Maranhão e a senha geral pré-configurada. Não há etapas de cadastro, nome de aparelho, recuperação ou autorização. Migração 007 aplicada ao Supabase permite sessões sem dispositivo.

Validação: 27 testes unitários, 16 testes Playwright (API, Chrome desktop e celular), lint, TypeScript, build de produção e testes PostgreSQL passaram. As operações de estoque, ferramentas, auditoria e concorrência foram exercitadas com sessão sem dispositivo em banco descartável.
